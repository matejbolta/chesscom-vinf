ChessComVINF Privacy Policy

No analytics, advertising or developer-operated servers.

Local operation

VINF adjusts the signed-in Chess.com homepage and supported game and review pages. Presentation preferences are stored locally in extension storage or Violentmonkey. These include card layout, presets, appearance, turn indicators and Pokémon selections.

Network activity

When Open Game is enabled, VINF sends the signed-in identifier only to Chess.com’s same-origin presence service to find an active game. The response is held in memory. There is no background polling, remote code, analytics or transmission to the developer.

Tab-local continuity

Two sessionStorage records hold the current game ID, clock reference maxima and rating-display expiry across refreshes. Ratings, credentials and account details are not stored. These records are overwritten for the next game and normally cleared when the tab closes.

Permissions

The desktop extension uses storage for preferences and sidePanel for optional local settings. The Android userscript uses Violentmonkey’s local settings/menu APIs and unsafeWindow to read native Chess.com context. Both versions run only on supported Chess.com routes.

See the complete privacy policy for precise routes and behavior.

Third parties

VINF does not sell data. Chess.com’s own requests remain governed by its policies. VINF is independent and unofficial, and is not endorsed by Chess.com.

Contact

For privacy questions or support, open an issue in the public GitHub repository.
